# COLOR LAB

Интерактивное исследование яркости и насыщенности изображений CIFAR-10 на marimo.

**[Открыть лабораторию](https://kristina344.github.io/ColorLab/)** · **[Исследование в Google Colab](https://colab.research.google.com/drive/1TIykhDkBmIEwg3NVIK4BqL7pTjnSKaP7?usp=sharing)**

На сайте: обработка фотографий, сравнение выборок, диаграмма зависимости 10 000 изображений, генератор случайных величин. Отчёт с математическими обоснованиями приведён в Colab.

## Файлы

- `photo_app.py` — приложение marimo.
- `colorlab.css` — оформление.
- `public/` — данные, изображения, стили для браузерной версии.
- `.github/workflows/pages.yml` — сборка GitHub Pages.
- `Photo(2).ipynb` — исходный исследовательский ноутбук.

## Публикация

GitHub Actions автоматически экспортирует marimo на главную страницу. Для работы сайта в браузере нужны интернет и поддержка WebAssembly. При проблемах с загрузкой библиотек доступно [полное исследование в Colab](https://colab.research.google.com/drive/1TIykhDkBmIEwg3NVIK4BqL7pTjnSKaP7?usp=sharing).
